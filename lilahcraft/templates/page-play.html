What’s different on Bedrock

Same server, same worlds, same rules. The differences:

  • TVs need a Java mod, so on Bedrock you won’t see or hear them.
  • The Linked Workbench is a plain crafting table for you. The Combo Chest reaches into nearby chests on both.
  • Sorting a chest: use /sort, or pick sneak-punch in /sort settings. There’s no outside of the window to double-click.
  • Menus put the key fact in each tile’s name. Press and hold a tile for the rest.
  • Mini golf: a ball you buy shows for you. A Mini’s head as your ball is Java only.
  • Mods, voice chat included, are Java only. You install nothing.

Say yes to the resource packs

When you join, the server offers two. Both are optional: saying no changes how things look, not what works.

LilahCraft clocks

Clocks tell the right time in every world.

CraftBridge models

3D models for the Linked Workbench and the Combo Chest, whose lid opens while it’s in use. Without the pack they’re a plain crafting table and barrel.

Said no by accident? In your server list, pick the server, click Edit, and set Server Resource Packs to Enabled.

Mods that make it better

None are required, and they're all Java only. Use Fabric: Collins needs it, and only there does JEI get the server’s recipes.

Get them on the Downloads page

JEI

Look up any recipe, the server’s own too on Fabric. Click + and the Linked Workbench fills the grid from your chests.

JourneyMap

A minimap and full map. The server tells it which world you’re in, so your maps don’t get mixed up.

Plasmo Voice

Proximity voice chat. Hear people when they’re close, lose them when they walk away.

CraftBridge Client

Lets the Combo Chest and Linked Workbench show every item in range, not just the first few dozen.

Collins

See and hear TVs: YouTube and Twitch on screens players put up. Fabric and Minecraft 26.3 only.

Good to know

LilahCraft runs out of a house in Minnesota and is open to anyone with the address.

Everyone plays together

Java and Bedrock players share one server and the same worlds, on a computer, phone, tablet, Switch or Xbox.

Claimed land is protected

Outsiders can’t build or break on land a town has claimed, or put up a TV there.

Deaths aren’t brutal

Your things wait in a grave for three hours. A craftable SafeLamp keeps hostile mobs away.

No pay-to-win

Arcade tokens can’t be bought with money and never turn into money. Prizes can’t be sold for money, only swapped item for item.

Voice chat is optional

It runs through Plasmo Voice, an optional Java mod, and you only hear players standing close by.

Nothing to install

Mods are optional. The one thing that needs a mod is seeing TVs: Collins, on Java. Bedrock players install nothing.

Family-friendly rules

Kids play here too, so chat, builds and TVs stay family-friendly.
